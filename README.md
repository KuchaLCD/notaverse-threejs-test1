**NotaVerse-BIM** — это легковесный и производительный 3D-движок на базе **C# WPF** и **Three.js**, разработанный для создания, хранения и редактирования интерактивных систем **цифровых двойников предприятий** и концепций IoT в масштабах оптимизированных 3D-моделей.

> ✨ *Проект полностью спроектирован, разработан и оптимизирован в синергии со сверточными моделями ИИ (DeepSeek AI Chat).*

## 🧠 Архитектура и Стек технологий

Движок объединяет надежность нативной Windows-платформы для работы с локальными данными и передовые веб-технологии для рендеринга сложной PBR-графики:

* **Frontend / 3D-Рендеринг:** `Three.js (r171)` (модули `OrbitControls`, `GLTFLoader`), HTML5, CSS3, ES6 Modules.
* **Backend / Хост-платформа:** `C# .NET 8.0 WPF`, `Microsoft.Web.WebView2` (Chromium Engine).
* **Связь (Interop):** Асинхронный нативный двусторонний мост передачи JSON-нотаций через `window.chrome.webview.postMessage`.
* **База данных:** Локальные изолированные `.json` конфигурации проектов.

## 🚀 Основные возможности и Фичи

### 1. Гибридный 3D-Рендеринг через WebView2
* Отказ от устаревшего нативного WPF 3D в пользу современного WebGL/Three.js с поддержкой мягких теней (`PCFSoftShadowMap`), тонального отображения (`ACESFilmicToneMapping`) и PBR-материалов.
* Бесшовный импорт тяжелых моделей `.glb` и `.gltf` напрямую из Blender.

### 2. Двухуровневая система режимов работы
* **👁 Режим просмотра (View Mode):** Обычный обзор сцены. Клик по элементу открывает интерактивную карточку цифрового двойника с его метаданными, динамическими полями и прикрепленными файлами.
* **✎ Режим инспектора (Edit Mode):** Инструмент инжиниринга. Наведение курсора подсвечивает грани объектов оранжевым цветом (Raycasting). Клик открывает меню кастомизации аннотаций, где можно изменять имя объекта и конструировать новые параметры.

### 3. Поддержка мультимедийных параметров объектов
* **Обычный текст:** Описание характеристик длиной до 2000 символов.
* **Гиперссылки:** Мгновенный переход на внешние интернет-ресурсы и IoT-панели.
* **Документы и Фото:** Прикрепление файлов (`.docx`, `.xlsx`, `.pdf`, `.png`, `.jpg`). Изображения рендерятся в виде превью прямо в WPF-интерфейсе, а клик по ним открывает файлы в нативных системных приложениях Windows.
* **Буфер обмена:** Быстрое копирование любого параметра в один клик.

### 4. Продвинутая система Проектов и Автономность
* **Полная портативность:** Приложение сохраняет относительные пути вложений. Папку с программой можно переносить между дисками без потери целостности ссылок.
* **Многодокументальный режим:** Нативная система проектов (Создание, удаление, сохранение и переключение между сценами). Программа помнит последний открытый проект.
* **Гибкая навигация:** Динамическое переключение управления камерой (вращение по клику ЛКМ с умным порогом смещения против срыва камеры или классический Blender-стиль по клику СКМ).

## 🛠 Установка и Запуск

### Требования
* ОС Windows 10 / 11
* IDE Visual Studio 2022 / 2026 Community
* Установленный компонент `.NET 8.0 SDK`

### Быстрый старт
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.comyour-username/NotaVerse-BIM.git
   ```
2. Откройте решение `.sln` в Visual Studio.
3. Убедитесь, что папка `node_modules` или локальные скрипты `Three.js` скопированы в директорию `wwwroot/lib/three/`.
4. Скомпилируйте и запустите проект (F5).

## 📂 Структура репозитория

```text
NotaVerseBIM.WebView/
├── Models/                     # C#-модели данных (SceneConfig, Объекты, Камера)
├── Services/                   # Бизнес-логика (DataService JSON, FileService)
├── wwwroot/                    # Веб-интерфейс для WebView2
│   ├── index.html              # HTML5-контейнер и Importmap зависимостей
│   ├── css/                    # Стили интерфейса сцены
│   └── js/
│       ├── threeScene.js       # Инициализация Three.js, Raycast, Свечение, Камера
│       └── interop.js          # JS-мост для Drag&Drop и обработки файлов
├── AttachedFiles/              # Локальное хранилище прикрепленных файлов (создается автоматически)
├── Models/                     # Внутреннее хранилище скопированных .glb моделей проектов
└── Projects/                   # Локальная база данных проектов в JSON-формате
```
